مشروع أدوات مبتدأ
===================

الملف الرئيسي للموقع هو index.html.

للنشر مجانًا على GitHub Pages:
1) أنشئ حسابًا أو سجّل الدخول إلى GitHub.
2) أنشئ مستودعًا جديدًا (New repository).
3) ارفع الملف index.html إلى المستودع.
4) افتح Settings ثم Pages.
5) اختر النشر من الفرع main ومن المجلد /(root)، ثم Save.
6) انتظر حتى يظهر رابط الموقع في صفحة Pages.

ملاحظة: لا ترفع كلمات مرورك أو بيانات خاصة إلى المستودع.
